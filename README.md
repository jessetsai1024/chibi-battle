# 赤壁之戰（建安十三年・西元 208 年冬）互動展示

以《三國志》及裴松之注為主要依據，考證赤壁之戰經過的單頁互動網頁，並對照《三國演義》的文學虛構。

線上瀏覽：https://jessetsai1024.github.io/chibi-battle/

## 內容
- **互動時間軸**（8 步）：劉表病卒 → 劉琮降曹 → 長坂之敗 → 孫劉結盟 → 赤壁對峙 → 黃蓋詐降火攻 → 烏林敗退・華容道 → 戰後三分之勢。支援上一步／下一步、點節點跳轉、鍵盤 ← →、手機左右滑動。
- **自繪 SVG 示意地圖**：長江、漢水與主要地點，隨步驟動畫顯示曹（藍）、劉（綠）、孫（紅）進退路線。
- **人物卡片**：曹操、劉備、孫權、周瑜、諸葛亮、魯肅、黃蓋、程普、劉琮、劉琦、曹仁、蔣幹。
- **史實 vs 演義**對照、演義虛構情節總表、史家爭議（兵力、疫病、地點、火攻、劉備角色）。

## 本地開啟
下載或 clone 本 repo 後，直接用瀏覽器開啟 `index.html` 即可，不需伺服器、不依賴外部服務。
